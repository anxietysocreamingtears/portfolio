# hugerain

Простой и понятный сайт-портфолио на обычных HTML, CSS и небольшом JavaScript.

Проект специально переписан без Framer-экспорта и сложных бандлов, чтобы его можно было открыть, прочитать и спокойно изменить руками.

## Где что лежит

- `index.html` — вся структура сайта и все тексты.
- `src/styles.css` — цвета, сетки, адаптив, карточки, кнопки и внешний вид.
- `src/main.js` — маленький скрипт для мобильного меню.
- `src/assets/` — понятные ассеты сайта: favicon и видео для первого экрана.

## Как менять сайт

Тексты меняются в `index.html`.

Цвета, отступы, размеры и адаптив меняются в `src/styles.css`. В начале файла есть блок `:root` с основными переменными.

Чтобы добавить новый проект, найди секцию `id="projects"` в `index.html`, скопируй один блок:

```html
<article class="project-card">
  ...
</article>
```

и поменяй внутри название, описание и статистику.
